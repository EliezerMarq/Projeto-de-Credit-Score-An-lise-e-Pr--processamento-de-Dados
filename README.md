Projeto de Ciência de Dados da EBAC focado na análise exploratória e no pré-processamento de dados de Credit Score, utilizando Python, Pandas, Matplotlib, Seaborn e Scikit-learn, incluindo tratamento de dados, visualizações e balanceamento de classes com SMOTE.

# 📊 Projeto Credit Score — EBAC

Este projeto foi desenvolvido como parte do curso de Ciência de Dados da EBAC, com foco no processamento e na análise exploratória de uma base de dados relacionada ao score de crédito.

O objetivo desta etapa é compreender a estrutura dos dados, identificar possíveis inconsistências e preparar as informações para análises mais aprofundadas, explorando características dos clientes e possíveis relações entre as variáveis.

## 🎯 Objetivos do projeto

- Compreender a estrutura e as características da base de dados.
- Identificar e tratar valores ausentes e possíveis inconsistências.
- Analisar variáveis numéricas e categóricas.
- Investigar a distribuição dos dados e possíveis valores atípicos (outliers).
- Criar visualizações para facilitar a interpretação das informações.
- Explorar relações entre características dos clientes e o score de crédito.

## 🛠️ Tecnologias e ferramentas

- **Python:** linguagem utilizada para processamento e análise dos dados.
- **Pandas:** manipulação, organização e tratamento da base de dados.
- **Matplotlib e Seaborn:** criação de gráficos e visualizações.
- **Plotly:** exploração visual e apresentação de informações.

## 📚 Aprendizados

A atividade permitiu aprofundar conhecimentos em análise exploratória de dados, tratamento de informações e interpretação de padrões. Também reforçou a importância de compreender a qualidade e as características dos dados antes de avançar para etapas de modelagem.

Este projeto faz parte da minha jornada de aprendizado em Ciência de Dados, na qual busco transformar os conhecimentos adquiridos em prática e construir um portfólio com projetos aplicados.
